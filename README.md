# Port Velour

An open-world crime game set in a harbor city at night. It runs in the browser from a single HTML file.

Open `port-velour.html` in a browser to play. It loads three.js from a CDN, so it needs an internet connection.

## Features

- First-person, chase-camera and top-down views (`V` to switch)
- A 20×20-block city with traffic, pedestrians, police and a helicopter at high wanted levels
- Twelve car models plus your own car, which waits at your apartment
- Pistol, SMG, shotgun and body armor
- Seven job types, store robberies, gun shops, the Chop Shop and Respray garages
- Forty hidden packages and a rank system that raises payouts
- Synthesized sound: engine, sirens, gunfire and a car radio

## Controls

| Key | Action |
| --- | --- |
| `W A S D` | Walk / drive |
| `E` | Enter or exit a car |
| `Space` | Handbrake |
| Mouse | Look and shoot (click the game to capture the mouse) |
| `J` | Shoot ahead |
| `Q`, `1`–`3` | Switch weapon |
| `V` | Change camera |
| `T` | Pick up a fare while driving a Cab |
| `R` | Car radio on/off |
| `H` | Horn |
| `P` / `Esc` | Pause and show the city map |
| `M` | Mute |

On a phone or tablet, on-screen buttons and a joystick appear.
